Search Tips

Use the advanced search to search specific fields or combine multiple criteria.

Search Fields

The advanced search allows you to search in specific fields:

  • Keyword: Searches all text content (title, full text, persons, places, uris)
  • Person Name: Searches only person names mentioned in entries
  • Place Name: Searches only place names mentioned in entries
  • URI: Searches entry URIs

Combining Search Terms

When using multiple search fields together, results must match ALL specified criteria.

For example, searching for:

  • Keyword: "monastery"
  • Place Name: "Mosul"
returns only entries about monasteries that mention Mosul.

Search Examples

Search for entries about a specific person:

Person Name: Ephrem

Search for entries mentioning a place:

Place Name: Edessa

Note: Searches are case-insensitive and match partial words. Results are paginated with 20 entries per page.
